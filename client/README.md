# Ignited Brains

Production frontend rebuilt in Next.js from the supplied design references.

## Requirements

- Node.js 20.9+
- npm 10+

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
npm run assets:check
```
