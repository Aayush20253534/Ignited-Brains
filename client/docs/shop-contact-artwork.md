# Shop and Contact artwork

Five original illustrations were generated with the built-in image generation tool for the Shop and Contact layouts. No existing page illustrations, photos, videos or background assets are used by these routes. The shared site branding remains unchanged. The images are visual concepts, not product listings or photographs of an actual Ignited Brains campus.

Each image was generated separately without source images. PNG masters were converted to WebP using Sharp, quality 87, effort 6. The learning-box image retains its alpha channel. The site uses responsive `next/image` sizes and preloads each route's hero.
