# Brand assets

Place final approved Ignited Brains logo exports here.

Recommended files when supplied by the client:

- `logo-primary.svg` for light backgrounds
- `logo-reversed.svg` for dark backgrounds
- `mark.svg` for favicon/app-icon contexts

Until the original vector logo is supplied, the existing shared `BrandLogo` component remains the canonical UI logo rather than tracing a tiny raster screenshot and pretending that is brand artwork.
